# 🤖 Modova Agente IA

Agente de inteligencia artificial que responde preguntas en lenguaje natural sobre las políticas y procesos de **Modova**, una tienda online de ropa, basado en documentación interna (PDF) usando RAG (Retrieval-Augmented Generation).

> Proyecto desarrollado para el **Challenge Alura Agente**.
